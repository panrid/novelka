# Карта сайту

Статус: пропозиція на погодження. Враховано [рішення власника](plan.md#рішення-власника). Макети: [mockups.html](mockups.html).

## Принципи
1. **Меню ділиться за тим, хто користується, а не за функціями.** Читач бачить лише
   читання й спільноту. Робота перекладача — «Студія». Адміністрування — окремий
   розділ, і його бачать лише ролі сайту.
2. **Один рівень навігації в розділі.** Ніяких вкладок у вкладках. На телефоні розділ
   Студії — це список-меню, а не рядок вкладок, що прокручується.
3. **Дія живе там, де її об'єкт.** «Керувати» — на сторінці новели. Перевірка правок —
   у читалці. Поповнення — поруч із залишком шагів.
4. **Звичайні адреси без `#`**: `/n/mag-vody/12`, а не `/#/novels/n0022gd/chapters/12`.
5. **Лише українська й людські назви.** Жодної японської, ID, кодів чи англійських
   технічних слів на жодному екрані, зокрема в Студії й адмінці. Див.
   [рішення 8](plan.md#рішення-власника).

## Навігація

**Телефон.** Нижня панель із п'яти пунктів:

| Пункт | Що там |
|---|---|
| Головна | Продовжити · Популярне · Нові глави · Нові переклади |
| Пошук | Каталог: пошук, теги, фільтри в шторці |
| Бібліотека | Мої списки: «Читаю», «В планах», «Прочитано», «Відкладено», «Кинуто» |
| Вхідні | Три вкладки: «Сповіщення» (згадки, відповіді, теги команди, нові глави), «Повідомлення» (особисті, групи, чати команд), «Чат» (загальний) |
| Я | Профіль, шаги, Студія, мої правки, налаштування, адміністрування, вихід |

Верхня шапка на телефоні — лише назва екрана і, де треба, «назад». У читалці нижня
панель ховається й з'являється від дотику.

**Desktop.** Ті самі п'ять пунктів ідуть у верхньому рядку. Пункти меню «Я» —
у випадному меню під аватаром.

## Маршрути

### Читання й спільнота — усі
| Адреса | Екран |
|---|---|
| `/` | Головна |
| `/catalog?q=&tags=&sort=&kind=` | Каталог |
| `/n/{novel}` | Новела. Якщо перекладів кілька — перемикач, `?t={team}` |
| `/n/{novel}/{номер}` | Читалка |
| `/n/{novel}/{номер}#c{id}` | Коментар у главі |
| `/u/{нік}` | Публічний профіль: аватарка, «про себе», переклади, внесок, кнопка «Написати» |
| `/team/{команда}` | Сторінка команди: учасники, переклади |
| `/library` | Бібліотека (після входу) |
| `/inbox` | Сповіщення (після входу) |
| `/inbox/messages` | Усі розмови: особисті, групи, чати команд; «Нова розмова», «Нова група» |
| `/inbox/messages/@{нік}` | Особиста розмова з людиною |
| `/inbox/messages/g/{назва-групи}` | Група |
| `/inbox/messages/${команда}` | Чат команди |
| `/inbox/messages/…/about` | Про розмову: учасники, назва, аватарка, вимкнути сповіщення, вийти |
| `/inbox/chat` | Загальний чат |
| `/login`, `/register`, `/reset`, `/verify` | Вхід і відновлення доступу |

### Я — після входу
| Адреса | Екран |
|---|---|
| `/me` | Меню «Я» (на телефоні); на desktop — перехід на `/u/{нік}` |
| `/me/wallet` | Шаги: залишок, «Поповнити», історія |
| `/me/wallet/buy` | Купівля пакета шагів (коли підключать оплату) |
| `/me/suggestions` | Мої правки: чернетки, на перевірці, прийняті |
| `/me/settings` | Аватарка, нік, «про себе», email, пароль, тема й читалка, сповіщення |
| `/me/settings/privacy` | Хто може мені писати, заблоковані люди, чи показувати «Читає зараз» |

### Студія — робота перекладача
| Адреса | Екран |
|---|---|
| `/studio` | Мої переклади (власник/перекладач/редактор) + «Новий переклад» |
| `/studio/new` | Новий переклад: посилання Syosetu → автопереклад, вручну або продовження вільного перекладу |
| `/studio/{tr}` | Огляд перекладу: глави, що відбувається зараз, бюджет, правки на перевірку |
| `/studio/{tr}/translate` | Автопереклад «до глави N» |
| `/studio/{tr}/chapters` | Глави: стан, остання ревізія, «Редагувати», «Додати главу» |
| `/studio/{tr}/chapters/{n}/edit` | Повний редактор глави |
| `/studio/{tr}/chapters/{n}/history` | Ревізії й diff |
| `/studio/{tr}/suggestions` | Черга правок, клік відкриває читалку в режимі перевірки |
| `/studio/{tr}/glossary` | Словник |
| `/studio/{tr}/about` | Обкладинка (завантажити й обрізати), назва, опис, теги, статус перекладу |
| `/team/{команда}/manage` | Команда: назва, учасники й ролі, внесок, бюджет у шагах і витрати |

### Адміністрування — модератор і вище
| Адреса | Хто | Екран |
|---|---|---|
| `/admin` | MODERATOR+ | Огляд: скарги, приховане, черга перекладів, баланс провайдера |
| `/admin/moderation` | MODERATOR+ | Скарги (коментарі, чат, особисті повідомлення, картинки), приховане |
| `/admin/users` | ADMIN+ | Користувачі й ролі сайту |
| `/admin/finance` | OWNER | Ручне нарахування шагів, пакети й ціни, платежі, собівартість шагу, книга записів |
| `/admin/settings` | OWNER | Моделі, реєстрація, ліміти, межа довгої глави, строк естафети (3 міс.) |
| `/admin/audit` | OWNER | Журнал дій |

## Ролі

Ролі сайту й ролі в команді — дві **незалежні** осі.

**Роль на сайті** (глобальна):

| Роль | Може |
|---|---|
| Гість | Читати, шукати |
| Користувач | Бібліотека, коментарі, чат, особисті повідомлення, правки, голоси, аватарка, свій переклад і команда, купівля шагів |
| Модератор | + розбирати скарги, приховувати коментарі, повідомлення чату й картинки; особисті повідомлення — лише поскаржені |
| Адміністратор | + приховувати новели, керувати ролями до модератора |
| Власник сайту | + нарахування шагів, фінанси, налаштування, журнал дій, призначення адміністраторів |

Адміністратор **не стає** автоматично перекладачем усіх новел. Для втручання в чужий
переклад (наприклад, приховати порушення) є окремі дії модерації.

**Роль у команді** (для перекладів команди):

| Дія | Власник | Перекладач | Редактор | Користувач |
|---|---|---|---|---|
| Читати, пропонувати правки (абзац, заміна, уся глава через редактор) | ✓ | ✓ | ✓ | ✓ |
| Погоджувати правки, публікувати ревізію | ✓ | ✓ | ✓ | — |
| Автопереклад, ілюстрації (з бюджету команди) | ✓ | ✓ | — | — |
| Поповнити бюджет команди зі своїх шагів | ✓ | — | — | — |
| Бачити витрати команди | ✓ | ✓ | — | — |
| Назва, склад, нова глава, дані перекладу, «покинуто», відповідь на запит естафети | ✓ | — | — | — |
| Отримувати сповіщення про тег команди `$назва` | ✓ | ✓ | — | — |
| Бути в чаті команди | ✓ | ✓ | ✓ | — |

Усі перевірки прав — в одній політиці на бекенді (`AccessPolicy`). Приховані кнопки
на фронтенді — лише зручність.
